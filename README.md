## 📌 Overview

**KIMPUL TWEAKS** is a lightweight, highly efficient shell script tailored for mobile gamers who want an edge in competitive gaming. Running natively through high-privilege execution environments like **Brevent**, **Shizuku**, or standard **ADB Shell**, it dynamically fine-tunes Android global properties, hardware acceleration pipelines, and background resource allocations on the fly. 

Unlike traditional flashing modules that risk permanent system corruption, KIMPUL TWEAKS operates securely within user-accessible system namespaces with zero risk of bootloops.

## 🔥 Core Features

| Feature | Description | Benefit |
| :--- | :--- | :--- |
| **⚡ UI & Touch Tuning** | Scales down window, transition, and animator durations. | Instant touch response & snappy visual feedback. |
| **🎮 GPU Acceleration** | Forces hardware-backed rendering properties (`debug.sf.hw`, `hwui`). | Minimizes dropped frames and maintains stable FPS. |
| **🧠 Smart Resource Control** | Manages background processes & disables strict execution modes. | Prevents sudden stutters during intense teamfights. |
| **🌐 Network Stabilization** | Disables WiFi sleep/suspend power-saving optimizations. | Cuts down packet loss and mitigates spike pings. |
| **🛡️ 100% Non-Root Safe** | Executes via ADB/Brevent namespaces without touching `/system`. | Zero risk of bricks, safety net trips, or bootloops. |
